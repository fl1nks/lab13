# Тихо — интернет-магазин для дома

Адаптивная витрина авторской керамики, текстиля и ароматов. В репозитории есть **preview-сайт** и самостоятельная тема WordPress с поддержкой WooCommerce.

## Быстрый просмотр

Откройте `index.html` напрямую или запустите локальный сервер из корня репозитория:

```bash
python3 -m http.server 4173 --bind 0.0.0.0
```

В preview работают фильтры и поиск по каталогу, сортировка, избранное, мобильное меню, корзина с сохранением в браузере и демонстрационное оформление заказа. Данные формы никуда не отправляются; Fondy в preview не подключён.

## Тема WordPress

Папка темы: `wp-content/themes/tikho-shop/`. Готовый архив для загрузки через WordPress: `tikho-shop-theme.zip`.

Тема включает главную страницу, шаблоны страниц и WooCommerce, подборку товаров из каталога, боковую корзину с WooCommerce AJAX-фрагментами, поддержку Elementor и точку подключения Contact Form 7. Если каталог WooCommerce пуст, главная показывает демонстрационные карточки — замените их реальными товарами.

Подробная установка на Beget и настройка тестовой оплаты описаны в [`WORDPRESS-SETUP.md`](WORDPRESS-SETUP.md). Перед публикацией замените демонстрационные контакты, тексты, товары, цены, изображения и условия доставки на свои.
